# AIOT 物联 Web 系统说明

> 正芯农牧 · 物联网监控与管理平台前端  
> 技术栈：Vue 3 + TypeScript + Vite + Element Plus + ECharts + Pinia

---

## 1. 系统概述

本系统面向养殖物联网场景，提供 **报警监控大屏** 与 **后台管理详情** 两类界面：

| 类型 | 特点 | 代表页面 |
|------|------|----------|
| 大屏可视化 | 固定视口、深色主题、一屏展示 | 报警监控大屏 |
| 后台详情 | 浅色卡片风格、支持纵向滚动 | 农场详情、舍详情、监控点位、数据对比 |

左侧 **组织树**（公司 / 工厂层级）在后台页面中统一提供工厂选择与场类型筛选，各详情页共享同一份选中状态（`useCompanyTree`）。

## 2. 页面与路由

### 2.1 导航结构

```
大屏可视化          /
农场详情            /farm
  └─ 舍详情（隐藏）  /farm/barn-detail
监控点位            /farm/monitor-detail
数据对比            /farm/comparison-detail
```

| 路由 | 页面名称 | 侧栏菜单 | 布局 |
|------|----------|----------|------|
| `/` | 大屏可视化 | ✅ 大屏可视化 | 独立全屏，无侧栏 |
| `/farm` | 农场详情 | ✅ 农场详情 | MainLayout + 组织树 |
| `/farm/barn-detail` | 舍详情 | ❌ 隐藏 | MainLayout，从农场详情跳入 |
| `/farm/monitor-detail` | 监控点位 | ✅ 监控点位 | MainLayout + 组织树 |
| `/farm/comparison-detail` | 数据对比 | ✅ 数据对比 | MainLayout + 组织树 |

> **说明**：舍详情不在侧栏展示；进入舍详情后，侧栏仍高亮「农场详情」。

### 2.2 页面跳转关系

```
大屏可视化 ──点击工厂/地图──► 农场详情（带 farmName / farmId）
农场详情   ──点击栏舍卡片───► 舍详情（带 id / name / factoryType）
农场详情   ──点击报警项─────► 舍详情（定位到对应栏舍）
舍详情     ──返回──────────► 农场详情
大屏       ──返回──────────► 农场详情
农场详情   ──监控大屏按钮──► 大屏可视化
```

## 3. 场类型

系统支持四种工厂类型，在组织树顶部下拉及农场详情页头可切换，全局状态同步：

| 值 | 名称 | 说明 |
|----|------|------|
| `pig` | 猪场 | 栏舍、存栏、饲料/用水消耗等 |
| `chicken` | 鸡场 | 鸡舍、产蛋量、料蛋比等 |
| `aquatic` | 水产 | 养殖池、溶氧、投饵量等 |
| `feed` | 饲料厂 | 生产车间、产量/出货量等 |

组织树数据通过 `@cpzxrobot/sdk` 的 `company.treenode` 接口加载，点击叶子节点即为选中当前工厂。

## 4. 页面功能说明

### 4.1 大屏可视化（`Dashboard.vue`）

**路由**：`/`  
**风格**：深色全屏，不支持页面内纵向滚动。

#### 顶栏
- 返回后台（跳转农场详情）
- 标题：正芯农牧 · 报警监控大屏
- 实时更新时间、全屏切换

#### KPI 条（可点击筛选）
| 指标 | 说明 |
|------|------|
| 当前报警 | 默认选中，联动右侧列表 |
| 严重报警 | 仅展示严重等级 |
| 涉及工厂 | 按工厂去重统计 |
| 今日新增 | 当日新产生报警 |
| 未处理 | 未处理报警数 |

#### 报警分布地图
- 全国 / 省级 / 市级下钻，颜色越深报警越多
- 省级：tooltip 显示报警数量
- 市级：tooltip 展示工厂列表及正常/报警状态，可点击跳转农场详情
- 右键返回上级地图
- 已过滤 GeoJSON 中重复的「境界线」标签

#### 右侧实时报警列表
- 展示全部报警，列表可滚动（无轮播）
- 点击条目：地图定位到对应城市并高亮
- 展示等级、时间、工厂名、省·市、报警描述
- **报警闭环**：处理状态标签（待处理 / 处理中 / 已关闭）、负责人、持续时长

#### 底部三小板块
| 板块 | 内容 |
|------|------|
| 重点工厂 | 报警数 TOP5；第一行：序号 + 工厂名 + 条数；第二行：省·市左对齐 |
| 报警等级 | 严重 / 一般 / 提示 占比条 |
| 报警类型 | 各类型报警数量占比条 |

#### 布局比例
- 地图区约 58%，右侧栏约 42%
- 地图 `layoutSize` 约 86%

---

### 4.2 农场详情（`FarmDetail.vue`）

**路由**：`/farm`  
**布局**：`LayoutWithSidebar`，内容区可纵向滚动。

#### 未选工厂
- 骨架屏 +「请选择工厂」提示
- 引导从左侧组织树选择，或使用页头场类型按钮

#### 页头
- 当前工厂名称、场类型标签、运行状态标签
- 场类型切换（猪 / 鸡 / 水产 / 饲料）
- 快捷跳转：监控大屏

#### 今日生产看板（厂长视角）
- 位于 KPI 条上方，按场类型展示当日核心指标
- **养殖场**：今日死淘、饲料/用水消耗、异常栏舍、未处理报警、当前批次信息
- **饲料厂**：今日产量/出货、异常车间、用水、离线设备等
- 部分指标附带较昨日变化

#### 环境达标摘要
- 全厂环境达标率（进度条）
- 异常栏舍数量、最差栏舍及偏离时长
- 未处理报警条数

#### KPI 条（可点击，联动下方列表）
- **猪场 / 鸡场 / 水产**：栏舍总数、当前报警、异常舍数、严重报警、离线设备、存栏/溶氧等
- **饲料厂**：报警、异常车间、严重报警、离线设备、总产量、各品类产出/出货等

#### 数据监测
- 近 30 日趋势图（ECharts）
- 可按栏舍筛选；鸡场可选肉鸡/蛋鸡，水产可选鱼/虾
- 指标随场类型变化（如猪：水耗/料耗/估重；水产：溶氧/投饵/pH）

#### 本厂报警
- 当前工厂报警列表，点击跳转对应 **舍详情**
- **报警闭环**：处理状态、负责人、持续时长、响应时间

#### 厂区监控
- 复用 `CameraPanel` 组件
- 可切换厂区摄像头（大门、仓库、中控室等）
- 支持刷新、全屏

#### 订单详情
- 表格展示：订单号、下单时间、交货时间、逾期时间、联系人、电话、状态
- 逾期订单标题旁显示「X 笔逾期」
- **履约统计**：今日待交 / 已完成笔数、本周与本月履约率

#### 栏舍 / 车间列表
- 卡片网格：名称、状态、核心指标、设备在线数、报警数
- 点击卡片进入 **舍详情**

### 4.3 舍详情（`BarnDetail.vue`）

**路由**：`/farm/barn-detail? id & name & factoryType`  
**风格**：后台浅色，三要素 **垂直排列**，可滚动。

#### 页头
- 返回农场详情
- 栏舍名称、状态标签、场类型
- 下拉切换同类型其他栏舍

#### 养殖与生产
- 顶部切换：**养殖** / **生产**
- **养殖**：
  - **环控数据**：实时环控与环控趋势见下方「环境数据」（已有，不重复）
  - **养殖生产数据**：补充品类、生产率、成活率、死亡率；存栏/日龄/死淘见「生物数据」
  - **饲喂采食**：饲喂量、增重量、料肉比（鸡场为料蛋比）、异常采食量报警
  - **生物防疫**：
    - 防疫消杀记录（表格）
    - 疫苗使用记录（表格）
    - 疫情报警（列表）
    - 体温记录（水产为水温；饲料厂为环境温度）
    - 异常行为 / 体征报警（列表）
- **生产**：
  - **饲料厂**三块结构：
    - 原料管控：原料入场（批次、重量、质检）、原料存量（库存预警）
    - 生产工艺管理：工艺图纸、工艺参数
    - 饲料出厂：批次、产量、合格率、产能统计、库存数量
  - **养殖场**（猪/鸡/水产）：保留原有产出摘要指标

#### 生物数据
- **批次信息栏**：批次号、进栏日期、日龄、初始/当前存栏、目标（如有）
- 基础 KPI（随场类型变化：存栏/死淘 或 溶氧/损耗 等）
- **专览指标**（场类型特有）：
  - **猪舍**：今日/累计饲料消耗、今日用水消耗、头均用水
  - **鸡舍**：饲料消耗、产蛋量、料蛋比、饮水量
  - **水产**：投饵量、换水量、溶氧、饵料系数
- 近 7 日趋势图（饲料+用水 / 饲料+产蛋 / 投饵+换水）
- **批次进栏至今曲线**：存栏与死淘双轴趋势（ECharts）

#### 环境数据
- 页头展示舍内达标率
- **环境达标**：温度 / 湿度 / 气体达标进度条，今日偏离累计时长
- 8 项实时指标（温度、湿度、CO₂、氨气等），异常项标红
- 近 30 日环境趋势图

#### 舍内监控
- `CameraPanel`，按当前栏舍 ID 过滤可用摄像头
- 可切换舍内多个监控点

#### 设备管理
- **在线情况**：设备在线率（进度条）、**离线设备列表**（名称、类型、编号、离线时长）
- **运行参数**：在线设备当前运行/监测参数表格
- **故障报警**：等级、设备、故障类型、处理状态、描述
- **设备详情**：见下方「设备详情」板块（已有，不重复）

#### 设备详情
- 设备卡片网格：在线状态、编号、类型、可控开关及运行参数
- **设备维保**：故障次数、下次维保日期、维保状态（正常 / 即将到期 / 已超期）

#### 能耗监测
- **能耗统计**：今日用电/用水/用气（或蒸汽）用量、较昨日变化、定额使用率
- **能耗报警**：异常波动、超定额两类报警，含当前值与阈值
- **排污与环保指标**：COD、氨氮等环保指标及达标状态

#### 生产安全
- **超限报警**：环控超限、设备超限、其他安全指标超限（当前值 / 限值 / 等级）
- **突发事件与处置**：事件类型、位置、处置状态、处置详情
- **应急资源管理**：消防设备、应急物资（数量、状态、最近检查）

### 4.5 数据对比（`ComparisonDetail.vue`）

**路由**：`/farm/comparison-detail`  
**布局**：组织树 + 区域统计分析，后台风格。

#### 页头
- 全平台 / 当前工厂上下文
- 场类型切换（影响 mock 数据维度）

#### 概览 KPI
工厂总数、存栏总量、报警总数、平均在线率、覆盖区域数

#### 本厂区域对标
- 当前工厂在同区域工厂中的排名（mock）
- 存栏规模、报警数量（越少越好）、设备在线率三项对标卡片

#### 成本指标
- 单头 / 单羽 / 单尾成本（随场类型切换单位）
- 饲料、用水、兽药（如有）单位成本

#### 区域工厂数量
- 柱状图：华东、华北、华南、华中、西南、西北、东北七大区域

#### 存栏 TOP5 省份
- 表格：排名、省份、区域、存栏量、工厂数、占比

#### 报警 TOP5 省份
- 横向条形图

#### 工厂类型分布
- 饼图：猪场 / 鸡场 / 水产场 / 饲料厂

#### 区域综合对比
- 表格：各区域工厂数、存栏、报警、设备在线率、场均存栏

#### 省份明细对比
- 可搜索省份
- 列：省份、区域、工厂数、存栏、报警、在线率、猪/鸡/水产场数量

> 数据来源于 `src/utils/comparisonMockData.ts`，后续可替换为 API。

## 6. 布局与交互规范

### 6.1 滚动策略

| 页面类型 | 滚动方式 |
|----------|----------|
| 大屏可视化 | 固定视口 `position: fixed`，内部板块各自控制溢出 |
| 后台详情页 | `MainLayout` 内容区 + 页面内容纵向滚动；组织树 sticky 固定 |

### 6.2 视觉规范

| 类型 | 背景 | 卡片 | 主色 |
|------|------|------|------|
| 大屏 | 深蓝渐变 `#0f172a` | 半透明面板 | 蓝 `#409eff`、报警红 `#f56c6c` |
| 后台 | 灰底 `#f0f2f5` | 白卡片 + 轻阴影 | Element Plus 默认色 |

### 6.3 图表

- 统一使用 **ECharts 5**
- 后台页图表为浅色主题（灰轴、白底 tooltip）
- 大屏地图基于 `chinese-global-compliant-geodata` GeoJSON
